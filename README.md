# Bismark Eli Kudjo — Personal Portfolio

A modern, fully responsive, dark-themed personal portfolio website built to showcase my background as a Computer Science student, along with my technical skills, projects, and professional journey.

## ✨ Features

- **Sleek Dark Theme:** Designed with a custom slate dark palette (`#0f172a` and `#1e293b`) paired with sky-blue accents and striking red action buttons.
- **Fully Responsive Layout:** Built using modern CSS Grid and Flexbox with mobile-first media queries to ensure a seamless experience across mobile phones, tablets, and desktops.
- **Pure HTML & CSS:** Crafted without any heavy frameworks or JavaScript libraries, keeping it lightning-fast and lightweight.
- **Complete Sections:**
  - **Hero Section:** Split-screen introduction with a professional portrait and quick bio.
  - **About Me:** Personal summary and background story.
  - **Skills:** Categorized breakdown of programming languages, web technologies, and tools.
  - **Projects:** Grid layout showcasing featured projects with live demo/GitHub links.
  - **Experience & Education:** Academic timeline (Ghana Communication Technology University) and practical experience.
  - **Get In Touch:** Contact section with email and social media links (LinkedIn, GitHub).

---

## 🛠️ Built With

- **HTML5** – Semantic document structure
- **CSS3** – Custom styling, Flexbox, CSS Grid, and responsive media queries
